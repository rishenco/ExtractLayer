# Corrections

One line per correction from the user, appended the moment it happens — not reconstructed at the end of a session, when recall of the early turns is weakest.

`/retro` reads this file and counts. A correction seen once is noise; the same correction twice is a pattern worth a rule.

Format: `YYYY-MM-DD — what was corrected, in the user's terms.`
